# Token clerk — the mill gate

1. **Cane Procurement → Gate · token issue.**
2. **Scan the indent** barcode, or type the number, or choose the truck's **ELP registration**.
3. The screen shows:
   - the grower, the indent's validity, the entry type (*ELP verified* or *Gate*)
   - the rates for this load: cane price, cess, subsidies, TPT
   - anything that blocks it: an expired or used indent, a blacklisted vehicle, a truck already inside
4. Enter or confirm the **vehicle number, vehicle type and driver** (name, CNIC, mobile for the bilty SMS).
5. **Issue token.** Print the token slip for the driver. The truck goes to the gross weighbridge.

## Rules
- One open token per vehicle.
- An indent can be used once, and only on its valid days.
- Without ELP verification, transport is paid at the gate rate (often none). The screen says so before you issue.

## Mistakes
A token issued by mistake can be **cancelled with a reason** before the gross weight. After that, ask the Cane Admin.
